# 옷장×코디 레퍼런스 묶음

빌드 지시서(Claude Docs의 "옷장×코디 빌드 지시서")와 함께 LLM에게 넘기는 자료입니다.
지시서가 규칙과 동작을, 이 묶음이 화면 모양·문구·데이터·이미지를 정합니다.
둘이 다르면 지시서가 우선합니다.

## 넣는 위치

프로젝트 저장소의 `reference/` 폴더에 이 묶음을 그대로 넣고, LLM에게 "reference/ 폴더를 먼저 읽어라"라고 알려 주세요.
`assets/`의 이미지는 앱의 `public/assets/`로 복사해서 씁니다.

## 구성

| 경로 | 내용 | 쓰는 법 |
| --- | --- | --- |
| `screenshots/` | 화면 19장. `d*`는 데스크톱(1440px), `m*`는 모바일(390px) | 완성 화면의 기준. 레이아웃·간격·문구를 이 그림과 맞춘다 |
| `design/*.dc.html` | 디자인 캔버스의 원본 소스 11개 + `canvas.json` | 치수·색·문구·상태 동작을 정확히 확인할 때 읽는다. 실행하는 파일이 아니다 |
| `seed-data.json` | 첫 실행 때 넣는 예시 데이터(옷 10벌, 룩 8개, 코디 4개, 쇼핑 리스트 2벌) | 그대로 IndexedDB에 넣는다. 판정 결과가 지시서의 기대 결과와 같아야 한다 |
| `svg/mannequin-paths.json` | 마네킹과 사진 없는 옷 모양의 SVG 경로(320×480 좌표계) | 그대로 쓴다. 다시 그리지 않는다 |
| `svg/mannequin.svg` | 마네킹 미리보기 | 확인용 |
| `assets/` | look.png(룩 사진), jacket.png·tee.png·pants.png(배경을 지운 옷), tee_original.png(배경 제거 전) | 예시 데이터와 옷 등록 예시에 쓴다 |

## design/*.dc.html 읽는 법

디자인 캔버스 전용 형식입니다. 브라우저에서 바로 열리지 않습니다.

- `<x-dc>` 안이 화면 마크업입니다. 인라인 `style`이 실제 치수와 색입니다.
- `{{이름}}`은 아래 스크립트의 `renderVals()`가 돌려주는 값으로 채워집니다.
- `<sc-for list="{{목록}}" as="x">`는 반복, `<sc-if value="{{조건}}">`은 조건부 표시입니다.
- `class Component extends DCLogic`의 `state`와 `setState`가 화면 상태(탭, 시트 높이, 입힌 옷 등)입니다. 이 동작을 React 상태로 옮기면 됩니다.
- 시안 안의 숫자(내 옷 N/M 등)는 시안용으로 직접 넣은 값입니다. 실제 앱에서는 `seed-data.json`과 판정 규칙으로 계산하고, 그 결과는 시안 숫자와 같아야 합니다.

## 파일과 화면 대응

| 파일 | 화면 |
| --- | --- |
| Landing | 1 랜딩 |
| Search | 2 검색 패널 |
| Explore | 3 룩 탐색 |
| Main | 4 피팅룸 |
| Closet | 5 내 옷장 |
| Shopping | 6 쇼핑 리스트 |
| Register | 7 옷 등록 |
| M_Landing / M_Explore / M_Fitting / M_Register | 모바일 랜딩 / 룩 탐색 / 피팅룸 / 옷 등록 |

모바일의 내 옷장·쇼핑 리스트·검색은 시안이 없습니다. 데스크톱 화면을 지시서의 모바일 규칙(하단 탭 바, 1열 목록, 시트, 하단 고정 버튼)으로 옮깁니다.

## 이미지 권리

look.png는 무신사의 AI 생성 룩 이미지, jacket·tee·pants는 쇼핑몰 상품 이미지에서 배경을 지운 것입니다. 개인 테스트용으로만 쓰고 공개 배포하지 않습니다.
